# 预训练与中训练数据周检

目标：仅根据用户指定的统计、清洗日志和质量报告，记录数据管线进展，并对比上周同口径结果。覆盖 L1/L2 token 规模与配比、MinHash/LSH 去重、n-gram Benchmark 去污及质量异常。

当前状态：尚未接入用户指定的数据入口，未获得真实统计；模板中的 `null` 代表未知，不能作为零值。历史目标不能作为本周实测。

## 接入与运行

1. 在 `config/sources.json` 添加用户明确指定且任务可访问的来源，字段参照 `templates/source.json`。服务器路径不会自动挂载；须提供可访问文件或脱敏报告。
2. 按 `templates/snapshot.json` 整理统计。每项指标必须带证据位置、采集时间、统计分母和口径；文件链接尽量固定到 Git SHA 或文件版本。
3. 已配置 ChatGPT 周检：每周一北京时间上午9点左右，首次计划为2026-11-23。每次运行先读取本仓库默认分支的 `config/sources.json`，仅使用 `user_designated=true` 的实际来源。每周读取最新来源，与上一周报告比较，将中文报告保存为 `reports/YYYY-MM-DD.md`。周检由 ChatGPT 定时任务发起，此仓库本身不运行清洗、去重或去污任务。
4. 缺来源、无本周新增数据、来源不可访问分别说明；首次只建立基线。没有数据时简短结束，不猜测指标或生成虚构建议。

## 统计规则

| 类别 | 必须保留的口径与指标 |
| --- | --- |
| L1/L2 | tokenizer及版本、语料范围、pipeline阶段、唯一token或训练采样token；L1/L2 token数及配比、目标单列；总量须说明是否包含其他层 |
| MinHash/LSH | 输入/输出doc和token、删除率及分母、shingle单位与长度、阈值、num_perm、seed、全局/分片去重、误删/漏删抽检 |
| Benchmark去污 | benchmark名称/版本、n、归一化、匹配字段、覆盖分母、命中doc、实际移除doc/token、残余污染抽检 |
| 数据异常 | 解析失败、不可解码、空白/短文本、重复、语言/领域/长度分布；记录各指标分母与抽检规模 |

仅相同 tokenizer、数据范围、阶段、采样口径、指标定义及处理配置计算环比。变化率为 `(本周-上周)/上周`；上周为0时相对变化标记不可计算。比例用百分点变化，不混用百分比。L1配比默认为 `L1/(L1+L2)`，仅在两者同口径时计算。

将结果分为：已验证的改进、潜在质量回退、未完成工作。数据规模增长、重复删除率上升、污染命中率下降均不能单独证明质量改善；需结合覆盖率、配置和固定抽检证据。

有数据时给出恰好两项优先验证建议，每项包括依据、最小动作、判定标准；缺数据时不凑建议。报告中的结论只能由引用证据支持。

## 提交范围

当前仓库为公开仓库。仅提交用户授权公开的指标摘要、脱敏证据索引和周报；未获公开授权的内部指标和来源仅在任务内报告。原始语料、benchmark原题、密钥与日志中的敏感字段不自动提交。周报同日期重复执行应更新原文件，避免重复条目。
